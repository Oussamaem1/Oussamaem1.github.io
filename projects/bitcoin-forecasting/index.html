Bitcoin Forecasting & Sentiment Dashboard

A forecasting project comparing a deep-learning model against a classical statistical baseline on Bitcoin price, enriched with sentiment extracted from news and social media, and delivered as a real-time Streamlit dashboard rather than a notebook.

Period
Academic project · EMINES – UM6P

Problem

Price series alone miss the narrative that moves a market. The project paired a conventional forecasting setup with a sentiment signal and put both in front of a user in real time.

Approach

  • LSTM forecasting benchmarked against an ARIMA baseline on the same series.
  • Sentiment analysis over news and social-media text as an additional signal.
  • A real-time Streamlit dashboard presenting forecasts and sentiment together.

Tools

  • Python
  • TensorFlow / Keras
  • LSTM
  • ARIMA
  • NLP
  • Streamlit

Technical domains

Time Series & ForecastingprimaryProduction & Deployment

Limitations

  • An academic exercise, not a trading system: no out-of-sample financial performance is claimed.
